---
name: Web Research
description: Research current public-web information with source-aware, cross-checked evidence.
tools:
  - web_search
  - web_open
  - web_find
  - web_download
---

Search broadly enough to find authoritative sources, then prefer primary sources for factual claims. Use recent sources when the question is time-sensitive. Cross-check consequential facts instead of relying on one result snippet. Open sources before relying on details that are not supported by the snippet. Separate sourced facts from inference, preserve useful source titles/URLs in the result, and stop once there is enough evidence to answer confidently.
