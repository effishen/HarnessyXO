HarnessyXO

VM setup shows controller activity, elapsed time, output counts and time since the last output. A live controller is not proof that the guest is Ready.

Use **Download Diagnostics** to collect sanitized operational evidence. Workspace, project and reference files and their contents are never included, including content echoed through command output or exceptions. Diagnostics retain reviewed states, timings, counts and fixed failure codes. There is no raw-content export mode.
